# Ward Pipeline 中文快速上手

這是給第一次使用的人看的簡版說明。

目標很簡單：

1. 把音檔放進來
2. 讓系統自動轉錄
3. 產出 SOAP 草稿
4. 匯出到 Obsidian
5. 需要時再傳到 Discord

## 你要先準備的東西

- Python 3.11
- `ffmpeg`
- Hugging Face token，若要跑 WhisperX diarization
- Discord bot token，若要送到 Discord
- `OBSIDIAN_VAULT_DIR`，若要匯出到自己的 Obsidian

## Windows 安裝

在專案根目錄開 PowerShell，執行：

```powershell
.\install-windows.ps1
```

如果你想一次完成預設設定和檢查，再跑：

```powershell
.\deploy-windows.ps1
```

## macOS / Linux 安裝

```bash
./install.sh
./deploy.sh
```

## 設定檔

把這些值放進 `.env` 或 `~/.hermes/.env`：

```env
HF_TOKEN=...
DISCORD_BOT_TOKEN=...
OBSIDIAN_VAULT_DIR=C:\Users\you\Documents\Obsidian Vault
WARD_LLM_PROVIDER=openai-compatible
WARD_LLM_BASE_URL=https://...
WARD_LLM_API_KEY=...
WARD_LLM_MODEL=...
```

## 最常用命令

### 查看設定

```bash
.venv/bin/python ward_cli.py config
```

Windows：

```powershell
.\.venv\Scripts\python.exe ward_cli.py config
```

### 處理單一音檔

```bash
.venv/bin/python ward_cli.py process /path/to/audio.m4a
```

Windows：

```powershell
.\.venv\Scripts\python.exe ward_cli.py process C:\path\to\audio.m4a
```

### 連續監聽資料夾

```bash
.venv/bin/python ward_cli.py watch-incoming
```

Windows：

```powershell
.\.venv\Scripts\python.exe ward_cli.py watch-incoming --incoming-dir C:\path\to\incoming
```

### 匯出到 Obsidian

```bash
.venv/bin/python ward_cli.py export-obsidian latest
```

## 建議流程

1. 先跑 `ward_cli.py config` 確認環境有讀到。
2. 處理一個音檔。
3. 檢查 `data/output/<job_id>/` 內的結果。
4. 打開 Obsidian 看 SOAP 草稿。
5. 如果有需要，再把結果送到 Discord。

## 常見問題

### 沒有 `ffmpeg`

- 先把 `ffmpeg` 裝好，並確認它在 `PATH` 裡。

### `HF_TOKEN` 找不到

- 放到 `.env` 或 `~/.hermes/.env`。

### Windows 不能用 launchd

- 對，`launchd` 是 macOS 專用。
- Windows 建議用 Task Scheduler 或 NSSM 去常駐執行 `watch-incoming`。

### Obsidian 沒有輸出

- 檢查 `OBSIDIAN_VAULT_DIR` 是否正確。

### 要先做什麼最簡單

先跑這個：

```bash
ward_cli.py process <audio_path>
```

如果你是 Windows，就用：

```powershell
.\.venv\Scripts\python.exe ward_cli.py process C:\path\to\audio.m4a
```
